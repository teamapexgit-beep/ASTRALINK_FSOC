ASTRALINK

AI-Based Virtual Camera Tracking System for Mobile Free-Space Optical Communication (FSOC)


1. Project Overview

ASTRALINK is a software-based virtual camera tracking system designed for coarse Pointing, Acquisition and Tracking (PAT) in Free-Space Optical Communication (FSOC).

The system creates a virtual environment where a moving optical beacon is detected and tracked using a virtual camera. It also allows tracking performance to be evaluated under different simulated disturbances.


2. Key Features

• Virtual camera simulation

• Moving optical beacon simulation

• Automatic beacon detection and tracking

• Pan and tilt camera control

• Kalman-based target prediction

• Atmospheric turbulence simulation

• Camera jitter simulation

• Platform motion simulation

• Real-time tracking telemetry

• Benchmark testing and performance analysis

• Performance graphs and reports

• 3D digital twin visualization

4. Performance Evaluation

ASTRALINK records tracking data during simulation and benchmark runs.

The system can evaluate parameters such as:

• Tracking error

• Maximum deviation

• Target loss

• Target recovery

• Tracking stability

• Response to disturbances

• Camera movement



5. Simulated Disturbances

ASTRALINK provides controlled disturbance scenarios to study tracking behavior:

• Atmospheric Turbulence

• Camera Jitter

• Platform Motion


Different disturbance levels can be applied during simulation.


6. Benchmarking

The system supports controlled target trajectories and ground-truth-based evaluation.

Tracked target data can be compared with the known target trajectory to calculate tracking performance and generate benchmark results.
